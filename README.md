# Renown Thar

A responsive Mahindra Thar fan website built as an HTML and CSS project.

## Pages

- Home, community stories, and demo contact form
- About and vehicle information
- Models and photo gallery

## Features

Responsive grids, shared CSS variables, keyboard focus states, reduced-motion support, and lazy-loaded gallery images. No build tools or dependencies are required. The contact form is a demonstration and does not deliver messages.

## Run locally

Open index.html in your browser, or serve this folder with a static web server (for example, VS Code Live Server).

This is an independent fan project and is not affiliated with Mahindra. Image and video rights belong to their respective owners.
